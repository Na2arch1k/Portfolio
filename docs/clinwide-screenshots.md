# Clinwide screenshots in the portfolio

The portfolio uses three different browser captures of the actual Clinwide source components:

- Hero product chip: `clinwide-finance-actual.png` — finances.
- About product scene: `clinwide-patients-actual.png` — patient card and treatment plan.
- Featured product card: `clinwide-schedule-actual.png` — appointment schedule.

These are the same source captures used by the Clinwide presentation site, with fictional fixture data and no connection to a patient database. The original components, navigation, fonts and CSS were rendered in an isolated local harness; these images are not AI-generated mockups.

The earlier `clinwide-schedule.png` is retained as an unused, recoverable asset. Details of the source captures are documented in `clinwide-site/docs/product-screenshots.md`.
